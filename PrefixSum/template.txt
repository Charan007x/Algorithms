// The below Templates are valid for immutable input only. Use Segment trees for mutable input

// Template -1 (1D prefix sum template) 

int pre[]=new int[n+1];
for(int i=1;i<=n;i++) pre[i]=pre[i-1]+a[i-1]; // pre[i] is the sum of first i elements

// for range query [l,h] {inclusive} 
int sum=pre[h]-pre[l-1]; // sum of elements from index l to h

Time Complexity: O(n) for precomputation, O(1) for each query
Space Complexity: O(n)

// Template -2 (2D prefix sum template)
int pre[][]=new int[n+1][m+1];
for(int i=1;i<=n;i++){
    for(int j=1;j<=m;j++){
        pre[i][j]=pre[i-1][j]+pre[i][j-1]-pre[i-1][j-1]+a[i-1][j-1]; // pre[i][j] is the sum of first i rows and j columns
    }
}

// for range query [l1,h1] to [l2,h2] {inclusive}
int sum=pre[h2][h2]-pre[l1-1][h2]-pre[h1][l2-1]+pre[l1-1][l2-1]; // sum of elements from index [l1,h1] to [l2,h2]

Time Complexity: O(n*m) for precomputation, O(1) for each query
Space Complexity: O(n*m)
